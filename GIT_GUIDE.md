## 🤔 Что такое Git?

> **Представьте:** Вы создаёте **сохранения** как в игре.
> Каждый раз, когда всё работает — делаете **сохранение** (коммит).
> Сломали что-то? **Загрузили** предыдущее сохранение!

```
Время ───────────────────────────────────────>
        │         │         │         │
       v1.0      v1.1      v1.2      v1.3
      (рабоч)  (сломал) (рабоч)  (текущ)
```

## 🚀 Начало работы

### Открываем терминал

| Способ | Действие |
|--------|----------|
| ⌨️ | Нажмите `Ctrl + \`` в VS Code |
| 🖱️ | Меню: **Terminal → New Terminal** |

### Проверяем что мы в проекте

```bash
git status
```

✅ **Всё хорошо**, если видите:
```
On branch master
Your branch is up to date with 'origin/master'.
nothing to commit, working tree clean
```

## 🛠️ Базовые команды

### 💚 Добавить изменения

```bash
# Добавить все файлы
git add .

# Добавить конкретный файл
git add Mini_Scale/Config.h
```

### 💾 Сделать коммит

```bash
git commit -m "Краткое описание изменений"
```

**Хорошие сообщения:**
```
✅ Исправил дребезг кнопки при нажатии
✅ Добавил режим калибровки по 5 точкам
✅ Увеличил время автоотключения до 180 сек
```

**Плохие сообщения:**
```
❌ фикс
❌ обновил код
❌ изменения
```

### 📜 Посмотреть историю

```bash
# Кратко
git log --oneline

# Подробно
git log --pretty=format:"%h - %s (%ci)"
```

**Пример вывода:**
```
ddda03d - Bump version string to v1.6.1 (2025-03-01)
17a8f84 - Refactor: extract helpers (2025-02-28)
ae0f89c - Add CoreLogic module (2025-02-25)
96c9810 - Fix double-tap detection (2025-02-20)
```

### 🔍 Посмотреть изменения

```bash
# Все изменения
git diff

# Конкретный файл
git diff Mini_Scale/ScaleControl.cpp
```

### 🟡 Сценарий 2: «Я всё сломал!»

**Проблема:** Изменили файл, но стало хуже

**Решение:**
```bash
# Отменить изменения в одном файле
git restore Mini_Scale/Config.h

# Отменить изменения во всём проекте
git restore .
```

> ⚠️ Это отменит **только несохранённые** изменения.
> Коммиты останутся в истории.

---

### 🔵 Сценарий 3: «Хочу старую версию»

**Проблема:** Текущая версия работает хуже старой

**Решение:**
```bash
# Посмотреть доступные версии
git tag

# Переключиться на старую версию
git checkout v1.6.0

# Вернуться к текущей
git checkout master
```

## 📋 Шпаргалка

| Что нужно | Команда |
|-----------|---------|
| 📊 Статус проекта | `git status` |
| 📝 Что изменилось | `git diff` |
| ➕ Добавить всё | `git add .` |
| 💾 Сохранить | `git commit -m "..."` |
| 📜 История | `git log --oneline` |
| ↩️ Откатить файл | `git restore файл` |
| ↩️ Откатить всё | `git restore .` |
| 🏷️ Список версий | `git tag` |
| 🔄 Переключить версию | `git checkout тег` |
| 🏠 Вернуться к master | `git checkout master` |

## ☠️ Опасные команды

> **НЕ ИСПОЛЬЗУЙТЕ** эти команды без понимания последствий!

| Команда | Последствие |
|---------|-------------|
| `git reset --hard` | 🔥 Удалит историю коммитов |
| `git push --force` | 🔥 Перезапишет удалённый репозиторий |
| `git clean -fd` | 🔥 Удалит все несохранённые файлы |
